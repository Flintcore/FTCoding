# FTcoding

> 数据不出网，越用越懂你的项目

FTcoding 是专为**中国开发者**打造的**本地优先** Coding Agent。你的代码、你的习惯、你的项目知识——全部留在本地，绝不外泄。

## 特性

- **本地优先**：所有代码分析、索引、学习都在本地完成
- **隐私安全**：数据不出网，支持本地大模型 (Ollama/llama.cpp)
- **越用越懂你**：自动学习你的编码风格、项目结构、常用命令
- **插件架构**：微内核设计，功能模块化，无限扩展
- **自迭代**：内置每日自动检查与功能迭代引擎

## 快速开始

```bash
# 安装
pip install ftcoding

# 启动
ftcoding

# 或在项目目录启动，自动学习项目
ftcoding --project /path/to/your/project
```

## 架构

```
┌─────────────────────────────────────┐
│  CLI / IDE Plugin                   │
├─────────────────────────────────────┤
│  Kernel (消息总线 + 插件管理)         │
├─────────────────────────────────────┤
│  Plugins: 代码理解 | 代码编辑 | 执行   │
├─────────────────────────────────────┤
│  Memory: SQLite + Chroma (本地)      │
└─────────────────────────────────────┘
```
